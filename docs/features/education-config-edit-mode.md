# Chế độ xem và sửa cấu hình kế hoạch giáo dục

Nguồn: user trực tiếp ngày 09/11/2026, CONFIRMED cho thay đổi giao diện Web.

- Sidebar Hiệu trưởng đặt Kế hoạch giáo dục trước Đánh giá trẻ.
- Trang Cấu hình kế hoạch giáo dục mặc định chỉ xem. Bấm Chỉnh sửa mới hiện ô nhập, thêm/xóa/sắp xếp và nút Lưu.
- Dùng kiểu nút Chỉnh sửa và thanh Lưu của kế hoạch năm học; tiếp tục lưu tay/Ctrl+S, cảnh báo khi rời trang có thay đổi chưa lưu. Lưu xong tiếp tục ở màn sửa như kế hoạch năm học.
- Giữ quyền hiện có theo BE:EDU-11/54/56: HT/PHT sửa lĩnh vực/dòng tuần; chỉ HT có quyền cấu hình mới sửa người tạo/duyệt và thời lượng. Không đổi API hay quyền server.
