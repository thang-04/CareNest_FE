# Folder Structure

Khi scaffold, ghi tại đây:
- Cây thư mục `src/` thực tế (1–2 cấp) và mục đích từng thư mục.
- Nơi đặt: API client theo vùng nghiệp vụ, type DTO, hook server state, component dùng chung, màn hình theo screen group (`docs/architecture/ROUTE_MAP.md`), test.
- Quy ước đặt tên file (cập nhật `.claude/rules/typescript.md` nếu khác PROPOSED).
- Cập nhật glob `paths:` trong `.claude/rules/*.md` cho khớp cấu trúc thật.
