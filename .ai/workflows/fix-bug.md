# Workflow sửa lỗi Web

1. Tái hiện lỗi với route, vai trò và dữ liệu tối thiểu; xác định hành vi mong đợi.
2. Lần theo component, state, API call và test liên quan; phân biệt lỗi FE với response/contract BE.
3. Sửa hẹp, kiểm tra trạng thái tải/rỗng/lỗi và quyền hiển thị liên quan.
4. Chạy test/build phù hợp với stack thực tế; báo rõ điều chưa kiểm chứng bằng trình duyệt hoặc API thật.
