# Workflow làm tính năng Web

1. Xác định actor, tác vụ người dùng, đường vào màn hình và tiêu chí hoàn thành.
2. Kiểm tra cấu trúc client hiện có, API/contract BE và các trạng thái giao diện cần xử lý.
3. Implement theo pattern đang dùng; không tạo business rule hay dữ liệu chuẩn mới trong client.
4. Kiểm tra thao tác chính, lỗi API, quyền hiển thị, responsive/accessibility phù hợp; phân biệt kiểm chứng tĩnh với visual/runtime.
