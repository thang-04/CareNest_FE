# Mockups & ảnh gốc

Ảnh thiết kế dùng làm chuẩn khi code giao diện. Không import các file này vào code
(ảnh dùng trong app nằm ở `src/assets/`).

| Thư mục / file | Màn hình |
|---|---|
| `brand/logo.jpg` | Logo gốc CareNest (nguồn để cắt `src/assets/brand/logo-mark.png`, `logo-full.png`) |
| `facility-transfer/LuanChuyen1.png` | PHT – Tạo phiếu, bước 1 Thông tin chung (cùng campus) |
| `facility-transfer/LuanChuyenCampus.png` | PHT – Tạo phiếu, bước 1 khi luân chuyển giữa các campus |
| `facility-transfer/LuanChuyen2.png` | PHT – Bước 2 Chọn tài sản |
| `facility-transfer/LuanChuyen3.png` | PHT – Bước 3 Chọn người thực hiện |
| `facility-transfer/LuanChuyen4.png` | PHT – Bước 4 Xác nhận và gửi |
| `facility-transfer/LuanChuyenTeacher1.png` | Giáo viên – Chi tiết phiếu khi là người bàn giao |
| `facility-transfer/PhieuIn.png` | Mẫu phiếu in A4 |

Module mới: thêm ảnh vào `mockups/<ten-module>/` (cùng tên thư mục với `src/features/<ten-module>/`).
